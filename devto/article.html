10 JavaScript Tips That Will Make You a Better Developer in 2024

#javascript #webdev #beginners

JavaScript keeps evolving, and staying on top of the latest patterns and tricks can make you significantly more productive. Here are 10 tips I've picked up this year that changed how I write code.

1. Optional Chaining is Your Best Friend

Stop writing nested if-checks. Optional chaining (?.) lets you safely access deeply nested properties without worrying about null or undefined.

// Instead of this
if (user && user.address && user.address.city) {
  console.log(user.address.city);
}

// Do this
console.log(user?.address?.city);

2. Nullish Coalescing Over OR

The ?? operator only falls through on null or undefined, unlike || which also catches falsy values like 0 and "".

const port = config.port ?? 3000;
// If port is 0, it stays 0 (not 3000)

3. Structured Clone for Deep Copies

Forget JSON.parse(JSON.stringify(...)). Use the built-in structuredClone():

const original = { name: 'dev', nested: { deep: true } };
const copy = structuredClone(original);

4. Array.at() for Negative Indexing

Access the last element of an array without arr[arr.length - 1]:

const colors = ['red', 'green', 'blue'];
console.log(colors.at(-1)); // 'blue'

5. Top-Level Await in Modules

In ES modules, you can now use await at the top level without wrapping in an async function.

6. Object.groupBy()

New in 2024 — group array items by a criteria:

const people = [
  { name: 'Alice', age: 25 },
  { name: 'Bob', age: 30 },
  { name: 'Charlie', age: 25 },
];
const grouped = Object.groupBy(people, p => p.age);
// { 25: [Alice, Charlie], 30: [Bob] }

7. Promise.withResolvers()

Create a promise and get its resolve/reject functions externally. No more wrapping in new Promise().

8. The using Keyword for Resource Management

TC39 stage 3: auto-cleanup resources when they go out of scope (like Python's with statement).

9. Temporal API for Dates

Say goodbye to Date headaches. The Temporal API is coming and it handles time zones correctly.

10. Pattern Matching (Stage 2)

Coming soon: match expressions that work like switch but return values and support destructuring.
