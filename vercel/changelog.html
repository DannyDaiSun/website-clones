Changelog

New updates and improvements to Vercel.

January 28, 2025
Feature

Vercel AI SDK 4.0

Major release of the AI SDK with streaming support for all major model providers. New features include structured output, tool calling, and multi-modal inputs.

  • 🤖 Stream responses from OpenAI, Anthropic, Google, and Mistral
  • 📝 Structured JSON output with Zod schemas
  • 🔧 Tool calling and function execution
  • 🖼️ Multi-modal inputs (text, images, PDFs)
Read documentation →
January 21, 2025
Improvement

Faster Cold Starts for Serverless Functions

Reduced cold start times by up to 60% for Node.js serverless functions. Improved caching and pre-warming strategies for frequently accessed routes.

  • ⚡ 60% faster cold starts for Node.js 20
  • 📊 New cold start metrics in Analytics dashboard
  • 🔄 Automatic pre-warming for high-traffic routes
January 14, 2025
Feature

Edge Config 2.0

Global key-value store with ultra-low latency reads. New SDK for reading configuration at the edge without cold starts.

  • 🌐 Read in under 1ms at the edge
  • 🔑 512KB store size (up from 64KB)
  • 🔄 Real-time updates via webhooks
Read documentation →
January 10, 2025
Fix

Build Pipeline Stability Improvements

Fixed several edge cases in the build pipeline that could cause intermittent failures for monorepo deployments.

  • 🐛 Fixed pnpm workspace detection for nested monorepos
  • 🐛 Resolved Turbopack cache invalidation issue
  • 🐛 Fixed environment variable resolution for preview branches
January 5, 2025
Feature

Web Application Firewall (WAF)

Protect your applications with enterprise-grade security. New managed rules for OWASP Top 10, rate limiting, and geo-blocking.

  • 🔒 OWASP Top 10 protection
  • 🚦 Rate limiting per route or IP
  • 🌍 Geo-blocking by country
  • 📋 Custom rule editor

Improvement

Next.js 15 Support

Full support for Next.js 15 including React 19, partial prerendering, and the new caching semantics.

  • 🔄 Partial Prerendering (stable)
