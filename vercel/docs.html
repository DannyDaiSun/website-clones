Introduction

Vercel is the platform for frontend developers, providing the speed and reliability innovators need to create at the moment of inspiration.

💡
New to Vercel?

Start with the Quick Start guide to deploy your first project in under 60 seconds.

What is Vercel?

Vercel is a cloud platform that enables developers to host websites and web services that deploy instantly, scale automatically, and require no supervision. It's the best place to deploy any frontend application.

Key Features

⚡ Instant Deploys

Push to Git and your changes go live in seconds. Every commit creates a unique preview URL.

🌐 Global CDN

Content served from 100+ edge locations worldwide. Your users get sub-50ms responses.

🔧 Zero Config

Automatic framework detection. No webpack, no build configs. Just push and deploy.

🔄 Preview Deployments

Every PR gets its own URL. Share with stakeholders, run E2E tests, and merge with confidence.

Quick Start

Terminal 
$ npm i -g vercel
$ vercel
🔗 Deployed → https://my-project.vercel.app

Supported Frameworks

Vercel supports 35+ frameworks out of the box, including:

  • ▲ Next.js — The React framework, built by Vercel
  • ⚛️ React — Create React App, Vite, and more
  • 💚 Vue / Nuxt — Vue.js ecosystem
  • 🟠 Svelte / SvelteKit — Cybernetically enhanced web apps
  • 🚀 Astro — The all-in-one web framework
  • 💎 Remix — Full stack web framework
