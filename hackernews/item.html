Rust is the most loved programming language for the 8th year in a row

(blog.rust-lang.org)
421 points by rustfan 3 hours ago | 287 comments

The Stack Overflow Developer Survey 2024 results are in. Rust continues its remarkable streak as the most loved programming language, with 87% of developers expressing a desire to continue using it. This marks the 8th consecutive year Rust has held this position.

Key findings from the survey include: memory safety concerns driving adoption, growing use in production systems, and the emergence of Rust in web development through WebAssembly.

I've been writing Rust professionally for 3 years now. The learning curve is real — it took me about 6 months before I felt productive. But once you get past the borrow checker struggles, it's genuinely one of the most enjoyable languages to work with.

The type system catches so many bugs at compile time that I rarely have production issues related to memory safety. That alone is worth the investment.

Counter-point: Go achieves similar safety with a much lower learning curve. The Rust borrow checker is a brilliant innovation, but for most backend services, Go's garbage collector and simple concurrency model is perfectly adequate.

I use Rust for systems-level work and Go for services. Both are excellent tools.

We migrated our embedded firmware from C to Rust last year. The initial port took longer than expected, but since then we've had zero memory-related bugs in production. Previously, those were roughly 40% of our bug reports.
